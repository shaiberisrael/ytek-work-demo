# Ytek Work — public demo

Russian / Hebrew interactive demonstration of work time, assignments, vehicles,
reports, and manager workflows.

- [Open the demo website](https://shaiberisrael.github.io/ytek-work-demo/)
- [Download Android APK 0.2.0](downloads/Ytek-Work-demo-0.2.0.apk)

iPhone users can open the website in Safari. The APK is for Android.
All people and work records are demonstration data. There is no real account
registration, GPS collection, or company server connection. Entered records reset
when the page is refreshed. Language and theme preferences are stored locally.

This repository contains only the distributable demo and APK, not project documents.
